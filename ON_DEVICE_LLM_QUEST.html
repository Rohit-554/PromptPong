PromptPong classroom quest

Wake up
the local AI.

This game can make silly dares with an AI model running on the device. Your job is to restore the hidden functions, one checkpoint at a time, and follow the path from button tap to generated answer.

App entry and shared game path

Android students begin at Level 1. iOS students begin at Levels 14 and 15 below, then return here at Level 5. These functions explain the game, its fallback answer, and the prompt sent to local AI.

Choose your platform path

Android uses a downloadable ONNX model. iOS uses Apple's built-in local model. After the shared game levels, continue with the platform you are using.

Turns that status into information the shared game can use.

AppleIntelligenceEngine.load

Hint: iOS needs no model download stage.

19
iOS

AppleIntelligenceService.checkAvailability

Swift checks the operating system, device, and Apple Intelligence status.

20
iOS

AppleIntelligenceEngine.generate

Kotlin passes the prompt to Swift and listens for response chunks.

Hint: This uses callbacks because it crosses a language boundary.

21
iOS

AppleIntelligenceService.generate

Apple's model creates a response locally and sends only newly added text.

Hint: The Swift stream gives the whole answer so far. Find the code that calculates only the new part.

22

Stops the current AI response when a round is cancelled.

Hint: Every good game needs a stop button.
